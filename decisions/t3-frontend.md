# T3 Code 前端决策

本文件适用于 Ade 对接 T3 Code 的架构边界，以及与现有“对话”功能的关系，编号前缀 `T3`。T3 Code 对接已整体移除，以下条目均已废止，仅保留记录。

### T3-001 Ade 作为 T3 Code 的另一个前端

- 状态：已废止（用户 2026-11-27 要求“移除t3功能”，对话只保留 Ade 自己的“对话”功能，即 `agent_chat`、`agent_harness`）
- 决策：原为以 T3 Code 官方 server 为后端、Ade 自己实现 WebSocket RPC 客户端和界面，与“对话”并行。
- 依据：用户 2026-11-25 明确提出“把当前ade的后端直接调用t3, 本项目只做对应的前端”，确认“是ade实现t3的前端部分吧？仿佛是t3的另一个前端一样”，并要求“现在开始开发，但暂时先不要移除ade的'对话'功能”。

### T3-002 T3 Code 对话可放在侧边面板或编辑区

- 状态：已废止（用户 2026-11-27 要求“移除t3功能”，随 T3-001 一并废止）
- 决策：原为 T3 Code 对话可作为右侧面板或编辑区标签页打开，并能来回移动。
- 依据：用户 2026-11-25 明确提出“我需要对话窗口不总是只在右侧窗口里，而是可以放到编辑区”。
