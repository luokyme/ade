# 标题栏设计决策

本文件适用于标题栏、状态栏、侧栏入口与编辑区标签栏的设计，编号前缀 `TITLEBAR`。

### TITLEBAR-001 标题栏只保留项目入口与常显菜单栏

- 状态：已取代（→ TITLEBAR-004）
- 变更原因：用户明确要求移除应用内菜单栏，改用 Winc 的面板布局。
- 依据：用户 2026-11-13 明确要求"移除顶部显示工作树和分支的功能，保留'最近的项目'，同时让菜单栏常显"。

### TITLEBAR-002 状态栏默认显示在标题栏右侧，位置可配置

- 状态：有效
- 决策：状态栏默认显示在标题栏右侧，用户可通过配置切换回窗口底部。
- 理由：用户希望将状态信息移至右上角，同时保留位置选择。
- 依据：用户 2026-11-13 明确要求“重构下状态栏，不再将起放在底部，而是放到靠右上角(当前标题栏)。做成一个可配置项吧”。
- 关联：TITLEBAR-007、`status_bar.position`。

### TITLEBAR-003 前进与后退按钮位于标题栏“最近的项目”左侧

- 状态：已取代（→ TITLEBAR-006）
- 变更原因：用户要求将项目入口和导航按钮靠左排列，并交换两组控件的顺序。
- 依据：用户 2026-11-16 明确要求“编辑窗口标题左侧的‘前进’和‘后退’按钮，放到顶部‘最近的项目’左侧显示”。

### TITLEBAR-004 应用内标题栏使用分段按钮切换侧栏

- 状态：已取代（→ TITLEBAR-006）
- 变更原因：用户将项目入口由居中改为靠左排列。
- 依据：用户 2026-11-22 给出 [Winc](https://github.com/DEEIX-AI/winc) 并明确要求移除菜单栏、调试面板和大纲，参照 Winc 呈现项目、搜索、Git 面板及编辑区标题。

### TITLEBAR-005 移除独立诊断视图和状态栏诊断入口

- 状态：有效
- 决策：移除项目诊断汇总页、独立文件诊断页和状态栏诊断入口。诊断信息通过编辑器内的提示与跳转、文件诊断标记呈现。
- 依据：用户 2026-11-23 明确要求“项目诊断功能可以完全去掉了”。
- 关联：TITLEBAR-002、`crates/ade/src/ade.rs`。

### TITLEBAR-006 标题栏左侧依次显示打开的项目和导航按钮

- 状态：已取代（→ TITLEBAR-007）
- 变更原因：用户要求将文件标签移到窗口标题栏，收起编辑区原有的标签栏。
- 依据：用户 2026-11-23 明确要求“把'前进'+'后退' 和 '打开的项目' 靠左排布。 并交换位置”。其余布局依据见 TITLEBAR-003、TITLEBAR-004。

### TITLEBAR-007 文件标签显示在窗口标题栏

- 状态：有效
- 决策：标题栏左侧的侧栏切换区域之后依次显示“打开的项目”和导航按钮，再显示胶囊形文件标签。编辑区省去独立的文件标签栏。导航按钮作用于当前活动窗格，受 `tab_bar.show_nav_history_buttons` 控制。标题栏省略窗口内应用菜单栏、当前工作树和 Git 分支的独立显示。默认在标题栏左侧通过分段按钮切换同一侧栏中的项目、搜索和 Git，工作区移除调试面板和大纲面板。
- 理由：用户希望将项目入口、导航按钮和文件标签集中在窗口标题栏。用户很少使用菜单栏、调试及大纲，侧栏切换和文件标签样式沿用 TITLEBAR-004 中参考 Winc 的选择。
- 依据：用户 2026-11-23 明确要求“把编辑区打开文件的titile 也放到标题栏中，不再保留编辑区原来的标题栏”。项目入口和导航顺序依据见 TITLEBAR-006。
- 关联：TITLEBAR-002、GITUI-001、`crates/title_bar/src/title_bar.rs`、`crates/workspace/src/dock.rs`、`crates/workspace/src/pane.rs`。

### TITLEBAR-008 标题栏文件标签使用紧凑布局

- 状态：有效
- 决策：标题栏的文件标签紧凑排列。可关闭的标签在鼠标悬停时于右侧浮动显示关闭按钮，按钮不占用独立横向空间。
- 理由：将横向空间留给文件名，在同一行显示更多文件标签。
- 依据：用户 2026-11-23 明确要求“编辑窗口的titile的横向空间需要紧凑点，并且关闭按钮不要占用独立的横向空间，鼠标放上去的时候靠右侧悬浮显示即可”。
- 关联：TITLEBAR-007、`crates/ui/src/components/tab.rs`、`crates/workspace/src/pane.rs`。
