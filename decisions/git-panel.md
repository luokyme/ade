# Git 面板布局

编号前缀：GITUI。涵盖范围：Git 面板分区、历史记录、工作区与历史差异页。

### GITUI-001 更改与历史记录上下分区，不使用标签页

- 状态：有效
- 决策：Git 面板不再用“更改 / 历史记录”标签页切换。面板按 Repositories、Changes、History 的顺序纵向排列，History 固定在底部。Changes 与 History 均展开时，两者之间的边界可以拖动，用来调整两个区域的高度占比。History 中每个提交只占一行。
- 理由：参照 VS Code 源代码管理视图，在同一屏同时查看待提交更改和提交历史。
- 否决：“更改 / 历史记录”双标签页，同一时间只能看到其中一个区域。
- 依据：用户 2026-11-15 明确要求“git面板不再做成'更改'和'历史记录'，而是把历史记录放到底部，并支持和变更区域的边界处拖动来改变占用区域的大小。另外就是历史记录每一条改成只占用一行”，并给出 VS Code 截图作为整体参照。
- 关联：[git_panel.rs](../crates/git_ui/src/git_panel.rs)。

### GITUI-002 工作区单文件差异页采用 Winc 的布局

- 状态：有效
- 决策：单文件差异页在顶部标明 HEAD、工作区和文件路径，并提供改动计数、差异块导航、文件导航和显示方式切换。默认折叠未改动的上下文，在差异块旁提供暂存、取消暂存与还原操作。
- 理由：用户希望在 Ade 中使用 Winc 的 Git Diff 页面。
- 依据：用户 2026-11-23 明确要求“把winc的git diff页面也抄过来”。参照 [Winc 差异页](https://github.com/DEEIX-AI/winc/blob/b7fb55d2119bd84175467b26da939fce66499212/crates/winc-app/src/view/diff.rs)。
- 关联：[solo_diff_view.rs](../crates/git_ui/src/solo_diff_view.rs)。
- 澄清：双栏保持各自的行布局，行号靠近中间，用经过抗锯齿渲染的曲线带连接对应改动。还原和暂存图标位于连接带对应的一侧。用户于 2026-11-23 给出效果截图，明确要求保留曲线带并解决边缘锯齿。
- 澄清：滚动任一侧时，两栏按对应内容同步。长删除或新增段按较长一侧的跨度滚过，折叠处以连续的细线连接两侧。用户于 2026-11-23 指出折叠接缝和滚动对齐问题。
- 澄清：纯新增块在左栏的对应插入位置显示与曲线带相接的横向细线。用户于 2026-11-23 通过纯新增块的截图明确了这一点。
- 澄清：左栏横向细线与曲线带连续呈现，右栏连接处省略竖向高亮条。用户于 2026-11-23 通过连接带截图明确了这两点。
- 澄清：曲线带两端与相邻差异块底色连续衔接，操作按钮在各自一侧的差异块内垂直居中。用户于 2026-11-23 通过差异块截图明确了这两点。

### GITUI-003 历史提交差异复用工作区的双栏呈现

- 状态：有效
- 决策：历史提交差异的双栏模式使用 GITUI-002 的曲线连接带、中央行号和按对应内容同步滚动。提交信息和文件导航仍由提交视图提供，历史文件快照保持只读。
- 理由：用户确认两类差异页应共享双栏比较体验。
- 依据：用户于 2026-11-23 确认将工作区差异的双栏呈现复用到 Git 历史提交差异。
- 关联：GITUI-002、[commit_view.rs](../crates/git_ui/src/commit_view.rs)。
- 澄清：多文件差异用空白补齐同一文件两侧的高度，在下一文件的标题处重新对齐。曲线连接带的两端省略竖向高亮条。用户于 2026-11-23 明确提出这两项要求。
