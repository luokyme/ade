# Git 面板

## 当前有效状态

- 用户希望 Git 面板参考 VS Code，并明确重点是 **Repositories**，后续讨论和改造优先围绕仓库浏览与切换展开。依据：用户于 2026-11-13 在本项目会话中澄清“我主要看重的是 vscode Git 面板的 Repositories”。
- 用户于 2026-11-14 表示不想再逐项调整，要求 Git 面板“照抄 VS Code 的”：已暂存/更改分组、行内悬停 +/−/撤销按钮、行尾状态字母、不区分已跟踪与未跟踪、点击文件只看单文件差异。后续改动默认向 VS Code 源代码管理视图对齐，不再逐项询问。
- 用户尚未回答“VS Code 自带多仓库列表”与“GitLens 仓库树”的区别问题。当前按自带列表推进属于助手的实施选择，不是用户确认的完整范围；不得据此把单仓库选择模式或具体交互登记为不可变设计决策。
